🚀 CRUD Management System

A full-stack CRUD (Create, Read, Update, Delete) web application built to strengthen my full-stack development skills. This project demonstrates secure authentication, OTP verification, REST API development, and MongoDB database management.

## 🛠️ Tech Stack

### Frontend
- Next.js
- Tailwind CSS

### Backend
- Node.js
- Express.js
- MongoDB
- JWT Authentication
- Nodemailer (OTP Verification)

## ✨ Features

- 🔐 JWT Authentication
- 📧 Email OTP Verification using Nodemailer
- ➕ Create Data
- 📖 Read Data
- ✏️ Update Data
- ❌ Delete Data
- 🔒 Protected Routes
- 🌐 RESTful API Architecture
- 📱 Responsive User Interface
- ⚡ Fast and Clean UI with Tailwind CSS
